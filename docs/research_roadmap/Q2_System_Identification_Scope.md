## 1. 三种飞行状态的本质差异

| 状态 | 主要控制执行机构 | 气动特征 | 辨识难点 | 优先级 |
|:-|:-|:-|:-|:-:|
| **旋翼态 (Multirotor / Hover)** | 16 个电机差速推力 | 无前飞速度、地效、桨间气流 | 共轴上下桨的下洗干扰（downwash） | ????? |
| **转换态 (Transition)** | 电机 + 气动面并用 | 气动面从"失速"到"有效"连续变化，升力分配剧变 | 最复杂：时变非线性 + 强耦合 | ??? |
| **固定翼态 (Fixed-wing / Cruise)** | 前推螺旋桨 + 副翼/升降舵/方向舵 | 传统飞行力学 | 大翼面 + 大载重的配平漂移 | ???? |

### 1.1 旋翼态（Hover）

#### 1.1.1 特征

- 飞行速度 V < V_stall（约 15 m/s）
- 气动力来源：16 电机垂直推力合成
- 气动面（副翼、升降舵、方向舵）**无效**（速度太低）
- 主要扰动：地效（起降时）、风场、载荷摇摆

#### 1.1.2 辨识难点

**共轴上下桨的下洗干扰（downwash）**：
- 上桨产生的气流会吹到下桨（距离 ~10 cm）
- 下桨的有效来流变化 → 推力系数变化
- 耦合系数 $\eta_{coaxial} = T_{下,实际} / T_{下,独立}$ 典型值 0.7–0.85
- **这是一个 TG700 独有的辨识参数**

**16 电机的相互气动影响**：
- 相邻舱位之间的气流干扰
- 内外侧电机的不同气动环境

### 1.2 转换态（Transition）

#### 1.2.1 特征

- V_stall < V < V_cruise（约 15–25 m/s）
- 升力来源：电机推力 + 气动升力（动态加权）
- 气动面从"失速"到"有效"的连续过渡
- 发生时间：典型 5–15 秒

#### 1.2.2 辨识难点

**时变 + 非线性 + 强耦合 = 系统辨识的最难场景**：

- 升力分配 $L_{total}(V) = (1-\sigma(V)) L_{motor} + \sigma(V) L_{wing}$
- $\sigma(V) \in [0,1]$ 是空速 V 的非线性函数
- 电机推力减少的同时，气动升力增加
- 任何一个电机提前/延后减推都会破坏平衡

**转换失败的典型故障**：
- 气动面还未有效，但电机已减推 → **掉高**
- 气动面已有效，但电机仍全推 → **过速**

### 1.3 固定翼态（Cruise）

#### 1.3.1 特征

- V > V_cruise（约 25+ m/s）
- 升力完全由机翼产生
- 推力由前推螺旋桨提供
- 16 VTOL 电机关闭或怠速

#### 1.3.2 辨识难点

**大翼面 + 大载重的配平漂移**：
- 翼展 11 m、载重变化 80%+
- 配平升降舵偏角随载重变化
- 纵向静稳定裕度随载重变化

**桨-翼气动耦合**：
- 前推桨的后洗流吹到主翼
- 改变主翼有效来流和升力
- 这是**传统辨识忽略、但 TG700 重要**的参数

## 3. 核心创新：非激励辨识（Non-excitation Identification）

### 3.1 问题

传统系统辨识需要"激励信号"：

| 传统激励 | 优点 | TG700 缺点 |
|:-|:-|:-|
| PRBS（伪随机二进制序列） | 辨识精度高 | 大载重 VTOL **极度危险**，撞机风险 |
| Schroeder 扫频 | 频域精确 | 飞行员操控困难 |
| Doublet（阶跃） | 简单 | 覆盖频段窄 |
| Multi-sine | 平衡 | 幅值过大会翻机 |

**核心矛盾**：大载重 VTOL **不能**做大幅度激励，但**不激励又辨识不准**。

### 3.2 解决方案

**用 Transformer 的长程相关性从"非激励的正常任务飞行"中挖掘动力学信息**：

- 输入：正常任务飞行日志（起飞 + 航点 + 降落）
- 输出：动力学参数
- 原理：Transformer 的 attention 机制能捕捉**弱激励下的微小响应差异**

**贡献声明（论文 motivation）**：

> 本文贡献是提出一种基于 Transformer 的非激励系统辨识方法，用正常任务飞行日志
> 实现与专用激励实验媲美的辨识精度，彻底消除大载重 VTOL 的激励实验风险。

### 3.3 实现路径

1. **数据收集**：100+ 份 TG700 正常任务飞行日志
2. **预处理**：IMU / RATE / ATT / RCOU / ESC 多通道对齐
3. **特征工程**：提取残差序列、相位差、频谱特征
4. **Transformer 模型**：
   - Encoder 编码飞行数据
   - Decoder 输出参数估计
   - 损失函数 = 预测误差 + 物理约束正则项
5. **验证**：
   - SITL 中用已知模型生成数据，测辨识精度
   - 真机数据 cross-validation
   - 对比 MLE、EKF 等传统方法

## 4. 系统辨识能力的 7 大衍生价值

### 4.1 所有后续控制器的模型基础

每一个先进控制律都需要动力学模型：

- **反步法**：需要  $\dot{x} = f(x) + g(x)u$
- **MPC**：需要离散状态空间 $x_{k+1} = A_k x_k + B_k u_k$
- **$H_\infty$**：需要传递函数 $G(s)$
- **滑模**：需要 $f(x)$ 上界
- **DRL**：需要仿真环境

**没有模型，一切免谈**。辨识能力是先进控制研究的入场券。

### 4.2 弥补 X-Plane/Gazebo 模型精度不足

X-Plane 里的 TG700 模型是参数估算的（您反馈精度有限）。辨识出的真实参数可以**反向
修正仿真器模型**，形成正反馈：

```
飞一次 → 日志辨识 → 更新 X-Plane → 仿真更准 → 控制器更好 → 飞得更好 → ...
```

### 4.3 飞行故障诊断基线

健康机的辨识参数是"**基准指纹**"。运行时：
- 在线辨识结果 vs 基准偏离 > 10% → 报警
- 偏离 > 30% → 自动返航
- 某个电机 $k_{T,i}$ 突降 → 该电机故障

### 4.4 载荷自适应控制的前置条件

TG700 是喷药 / 测绘 / 运输用机型：
- 喷药时质量**实时变化**（喷洒流失）
- 运输时载荷**随机放置**（重心偏移）
- 必须**在线辨识 m?** 才能自适应控制

### 4.5 扰动观测器（DOB）的模型基础

DOB 的核心公式：

$$\hat{d} = \dot{y} - f(x, u)$$

右边的 $f(x,u)$ 就是**辨识出的标称模型**。没有好的 f，DOB 就无意义。

### 4.6 飞行边界自动保护

辨识出：
- 失速角 $\alpha_{stall}$
- 翻滚极限 $\phi_{max}$
- 过载极限 $n_{max}$

**飞控自动限制**在安全包络内（Flight Envelope Protection）。

### 4.7 机队批量健康管理

多架 TG700 辨识结果聚合：
- 老化趋势分析（电机推力 10% 下降 → 该批次寿命到）
- 预测性维护
- 透明度超过 DJI / 大疆的闭源方案
