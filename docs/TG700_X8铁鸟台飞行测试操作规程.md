## ⚠ 强制约束声明（操作前必读）

| 编号 | 约束 | 根因 | 处置 |
|---|---|---|---|
| C-1 | **禁止执行磁力计校准** | 铁鸟台金属结构强干扰，校准数据必然失真 | 参数中全部关闭罗盘，依靠加速度+陀螺融合 |
| C-2 | **IMU1（第二IMU）必须全程关闭** | M9 飞控 IMU1 X/Y轴数据存在固件故障 | `INS_USE2=0, EK3_IMU_MASK=1` |
| C-3 | **全程无GPS辅助** | 无GPS模块安装 | `GPS1_TYPE=0`，使用DCM姿态+气压计高度 |
| C-4 | **铁鸟台拉力额定值不得超限** | 结构安全 | X8最大推力核算后须低于台架额定载荷 |
| C-5 | **800V主母线上电前须完成全部地面检查** | 800V高压触发大电流损毁风险 | 上电顺序严格遵守本文第6节 |

## 4. 传感器校准操作

> 约束说明：无GPS，禁罗盘校准。仅执行**加速度计校准（水平简易模式）**和**飞控水平校准**。
> 铁鸟台约束：机体已固定于台架，无法完成六面翻转。执行铁鸟台专用简易校准流程。

### 4.1 飞控水平校准（Level Horizon Calibration）

**适用条件**：飞控/机体已安装固定，台架调平后执行。

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| LH-1 | 用水平仪确认铁鸟台（及机体）在X、Y方向均水平 | 气泡处于正中，偏差 ≤0.2° |
| LH-2 | Mission Planner → Initial Setup → Mandatory Hardware → Accel Calibration → **Calibrate Level** | 点击后飞控LED快闪 |
| LH-3 | 等待Mission Planner提示"Calibration successful" | 出现绿色成功提示 |
| LH-4 | Mission Planner → Flight Data → HUD → 查看人工地平线 | HUD地平线与实际水平面一致，偏差 ≤1° |
| LH-5 | 在 Full Parameter Tree 确认写入：`AHRS_TRIM_X ≈ 0, AHRS_TRIM_Y ≈ 0`（铁鸟台水平则应接近0） | 两值绝对值均 ≤ 0.05 rad（约2.9°） |

### 4.2 加速度计简易校准（铁鸟台水平单位置模式）

> **说明**：六面翻转校准需拆卸上架，若首次使用前已在工作台完成六面校准，此步仅做验证。若需重新校准，先拆下飞控单独校准后再安装回机体。

**场景A：已有历史校准数据，执行验证**

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| ACC-V1 | Mission Planner → HUD → 查看 Roll/Pitch 显示 | 机体水平时 Roll ≈ 0°, Pitch ≈ 0°（偏差 ≤1°） |
| ACC-V2 | 手持遥控器模拟轻微倾斜机体（如条件允许松开单边固定螺栓） | HUD Roll/Pitch随机体倾斜方向同步变化，无反向或迟滞 |
| ACC-V3 | MAVInspector → 查看 `RAW_IMU` xacc/yacc/zacc | 机体水平时：xacc≈0, yacc≈0, zacc≈-9.8 m/s² |

**场景B：需要重新执行加速度计校准（飞控离机校准）**

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| ACC-1 | 拆下Zero One M9飞控，置于水平工作台 | 台面水平度 ≤0.3° |
| ACC-2 | 连接USB，打开Mission Planner → Accel Calibration → **Calibrate Accel** | 进入6面校准流程 |
| ACC-3 | 按提示依次完成：水平、右侧、左侧、机头朝下、机头朝上、反转 | 每面提示"Done"后点击Continue |
| ACC-4 | 完成后 Mission Planner 提示 "Calibration successful" | 绿色成功提示 |
| ACC-5 | 重新安装飞控于机体，注意安装方向与原位一致 | 飞控安装方向标记与机头一致 |
| ACC-6 | 重新执行飞控水平校准（步骤4.1） | 同4.1核验标准 |

## 5. 电机系统预检（800V主母线上电前）

### 5.1 DroneCAN 节点状态核验

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| DCA-1 | 飞控上电（24V），确认陆科电源**主母线OFF**状态 | ESC无旋转，飞控LED正常亮起 |
| DCA-2 | Mission Planner → Setup → Optional Hardware → **DroneCAN/UAVCAN** | 打开DroneCAN监控面板 |
| DCA-3 | 陆科电源主母线上电（OCP=80A），等待3-5秒 | 8个ESC节点均出现在节点列表中 |
| DCA-4 | 核查CAN1总线节点数量 | 应显示4个节点（P2前右内、P6后右内各2个ESC） |
| DCA-5 | 核查CAN2总线节点数量 | 应显示4个节点（P3前左内、P7后左内各2个ESC） |
| DCA-6 | 确认无重复节点ID（DNA冲突报警） | 无红色冲突警告；`CAN_D1_UC_NODE` 和 `CAN_D2_UC_NODE` 无冲突 |

> **故障处置**：若节点数量不足，先检查CAN接线，再检查ESC供电；若出现DNA冲突，参考 `docs/flight_reports/20260414_dronecan_dna_duplicate_node_analysis.md`。

### 5.2 电压电流监控确认

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| VM-1 | Mission Planner → Flight Data → HUD → 底部电池显示 | 显示总线电压，应为 **780V-820V**（陆科800V目标） |
| VM-2 | Mission Planner → Flight Data → Status → `battery_voltage` | 与电源表显示一致，偏差 ≤10V |
| VM-3 | 当前静态电流（无输出） | `battery_current` < 5A（仅飞控和ESC待机电流） |
| VM-4 | Mission Planner → Setup → DroneCAN → 选中各ESC节点 → 查看 `voltage` / `current` | 各ESC节点电压与总线电压一致，电流值非零但接近0 |

### 5.3 电机顺序测试（Motor Test）

> ⚠ **执行前置条件**：铁鸟台围栏已设立，所有人员退出桨盘2m范围，电源安全员就位PDU急停按钮。

| 步骤 | 操作 | 预期电机 | 物理位置 | 核验标准 |
|---|---|---|---|---|
| MT-1 | Mission Planner → Optional Hardware → **Motor Test** | - | - | 解锁前模式，输出受限 |
| MT-2 | Test Motor **A**（10%油门，3秒） | Motor1 | **P2 前右内 上桨** | 仅P2吊舱上桨旋转，其余静止 |
| MT-3 | Test Motor **B** | Motor2 | **P2 前右内 下桨** | 仅P2吊舱下桨旋转 |
| MT-4 | Test Motor **C** | Motor3 | **P6 后右内 上桨** | 仅P6吊舱上桨旋转 |
| MT-5 | Test Motor **D** | Motor4 | **P6 后右内 下桨** | 仅P6吊舱下桨旋转 |
| MT-6 | Test Motor **E** | Motor5 | **P3 前左内 上桨** | 仅P3吊舱上桨旋转 |
| MT-7 | Test Motor **F** | Motor6 | **P3 前左内 下桨** | 仅P3吊舱下桨旋转 |
| MT-8 | Test Motor **G** | Motor7 | **P7 后左内 上桨** | 仅P7吊舱上桨旋转 |
| MT-9 | Test Motor **H** | Motor8 | **P7 后左内 下桨** | 仅P7吊舱下桨旋转 |
| MT-10 | 目视确认旋转方向 | 上桨（Motor奇数） | 应为**CW（顺时针）** | 从上方俯视顺转 |
| MT-11 | 目视确认旋转方向 | 下桨（Motor偶数） | 应为**CCW（逆时针）** | 从上方俯视逆转 |
| MT-12 | 确认外排4个吊舱（P1/P4/P5/P8）无任何响应 | - | 外排断电 | 8个外排电机全程静止 |

> **不合格处置**：
> - 电机未转：检查对应SERVO_FUNCTION赋值和ESC_BM，确认CAN节点在线；
> - 旋转方向错误：交换对应电机的任意两根三相线，或在ESC参数中修改换向；
> - 外排电机意外旋转：立即断电，检查外排ESC是否未断电或接线错误。

## 7. 起飞与悬停操作规程

### 7.1 解锁程序

| 步骤 | 操作员 | 操作内容 | 核验标准 |
|---|---|---|---|
| ARM-1 | 遥控手 | 确认油门最低，CH5拨至QSTABILIZE | MP显示QSTABILIZE |
| ARM-2 | 飞控操作员 | 声令："准备解锁" | 各岗位回复"就绪" |
| ARM-3 | 遥控手 | 执行解锁动作（右摇杆右下角保持2秒） | MP Messages："Armed successfully"；电机以怠速低转 |
| ARM-4 | 飞控操作员 | 确认MP状态：ARMED，电池电流约5-15A（怠速） | 电流无异常跳变 |
| ARM-5 | 所有人员 | 二次确认无人在桨盘范围内 | 声令确认 |

### 7.2 油门渐进爬升（QSTABILIZE模式）

> 策略：QSTABILIZE模式下，飞控姿态稳定，油门100%由遥控手控制。在铁鸟台约束下，起飞过程即为对电机输出的系统性验证。

| 步骤 | 操作 | 油门目标 | 核验标准 | 异常停止条件 |
|---|---|---|---|---|
| T-1 | 油门缓慢推至10%，保持5秒 | ~10% | 8个电机全部低速旋转，声音均匀无异响 | 任何电机不转或异响→立即降至0 |
| T-2 | 油门推至20%，保持5秒 | ~20% | 机体无振动，电流 < 30A，电压无骤降 | 振动过大或电流突增→降至0 |
| T-3 | 油门推至30%，保持5秒 | ~30% | 台架开始受力，铁鸟台无异常晃动 | 台架晃动→降至0 |
| T-4 | 油门缓推至**悬停点附近（约50%）** | ~45-55% | 机体姿态稳定，铁鸟台拉力显著增大 | 姿态无法维持→降至0 |
| T-5 | 在悬停油门处保持**10-15秒** | 保持稳定 | Roll/Pitch偏差 ≤±5°，无偏转趋势，电流稳定 | |

> 🔍 **关键观测点**：
> - 飞控操作员全程监视MP HUD上的Roll/Pitch显示，报告任何超过±3°的漂移
> - 电源安全员实时报告电流读数（正常悬停约30-50A）
> - 若Q_M_THST_HOVER学习正常，约5次解锁悬停后参数自动更新

### 7.3 定点悬停（切换QHOVER模式）

> **前提**：QSTABILIZE悬停通过后，方可切换QHOVER。

| 步骤 | 操作 | 核验标准 |
|---|---|---|
| QH-1 | 在悬停油门附近（~50%），遥控手将CH5拨至QHOVER位置 | MP显示"QHOVER"模式 |
| QH-2 | 松开油门摇杆至中位（QHOVER以中位为基准） | 飞控接管高度控制，气压计稳定 |
| QH-3 | 保持QHOVER悬停30秒 | `baro_alt` 波动 ≤±0.3m，机体无明显俯仰漂移 |
| QH-4 | 飞控操作员记录：电压、电流、Q_M_THST_HOVER实时值 | THST_HOVER学习值若稳定（变化<0.01/次），可停止学习 |
| QH-5 | 微量Roll/Pitch杆输入，观察姿态响应 | 响应灵敏不震荡，释放后回中 |
| QH-6 | 偏航（Yaw）响应测试 | 小量偏航输入，机体平稳左右转动，无明显侧移 |

### 7.4 电压电流全程监控指标

| 监控项 | 正常范围 | 警告阈值 | 处置动作 |
|---|---|---|---|
| 总线电压 | 780-820V | < 740V | 即时降落，检查电源 |
| 悬停电流（X8@200kg） | 30-55A | > 70A | 降低油门，检查电机 |
| 单ESC温度（如有遥测） | < 80°C | > 100°C | 降落冷却 |
| `battery_voltage`（MP） | 780-820V | < 720V → BATT_LOW触发 | 飞控自动QLAND |

## 8. 降落操作规程

### 8.1 主动降落（正常结束）

| 步骤 | 操作员 | 操作内容 | 核验标准 |
|---|---|---|---|
| L-1 | 遥控手 | CH5切回QSTABILIZE（若在QHOVER） | MP显示QSTABILIZE |
| L-2 | 遥控手 | 缓慢降低油门，每次降低5-10%，停顿2秒 | 机体稳定下降，无俯仰翻转倾向 |
| L-3 | 遥控手 | 油门降至约15-20%时观察台架受力减少 | 台架振动消失，拉力接近零 |
| L-4 | 遥控手 | 油门缓降至最低位（0%） | 电机降至怠速 |
| L-5 | 飞控操作员 | 声令："加锁" | |
| L-6 | 遥控手 | 执行加锁动作（右摇杆右下角保持2秒） | MP Messages："Disarmed"；电机停转 |
| L-7 | 飞控操作员 | 确认状态 | MP显示DISARMED，电流恢复 < 5A |

### 8.2 紧急降落（异常情况）

| 触发条件 | 遥控手动作 | 电源安全员动作 |
|---|---|---|
| 机体剧烈震荡/失控 | 油门最低 → 立即加锁 | 不需触发PDU，等飞控指令 |
| 电压低于680V（临界告警） | 立即切QSTABILIZE，主动降落 | 报告电压，准备切断 |
| 任意CAN总线断开（电机部分失效） | 立即油门最低加锁 | **立即按PDU急停** |
| 机体结构异音（桨/吊舱松动） | 立即油门最低加锁 | **立即按PDU急停** |
| 铁鸟台固定松脱 | **立即按下遥控急停（若有）** | **立即按PDU急停** |

## 10. 特殊配置说明（无GPS/无罗盘/单IMU场景）

### 10.1 DCM姿态估计模式（AHRS_EKF_TYPE=0）

| 特性 | 说明 |
|---|---|
| 姿态来源 | IMU0 加速度计 + 陀螺仪融合（DCM算法） |
| 高度来源 | 气压计（BMP/MS5611）|
| 位置来源 | **无**（GPS/光流均未接入） |
| 适用模式 | QSTABILIZE（完全可用）/ QHOVER（气压计高度可用）|
| 不可用模式 | QLOITER（需GPS位置）|
| 偏航漂移 | 无罗盘时偏航长时间保持依赖陀螺积分，存在缓慢漂移，铁鸟台下可接受 |

### 10.2 铁鸟台场景下的QHOVER精度预期

| 性能指标 | 预期表现 |
|---|---|
| 高度保持精度 | ±0.3-0.5m（气压计受地效和风影响） |
| 姿态稳定精度 | Roll/Pitch ±2-5°（视风速和PID调节） |
| 偏航漂移 | <10°/分钟（陀螺积分误差，铁鸟台下无影响） |
| 位置保持 | **由铁鸟台机械约束实现**，飞控不做位置控制 |

### 10.3 偏航权威监控

X8构型偏航权威弱于COAX16。若测试中发现偏航响应迟缓：

```
Q_A_RAT_YAW_P: 0.40 → 0.50（最大不超过0.70）
Q_A_RAT_YAW_I: 0.04 → 0.06
```
调整后 Write Params，重启飞控后重新测试。
