# TG700 同轴X8 改造方案 v2

> **机型**: ZeroOne M9 飞控 · TG700 骨架  
> **目标**: 外排8个电机断电，保留内排4个吊舱（共8电机），实现同轴X8构型  
> **核心特性**: 无需重新烧写ESC固件，硬件仅断开外排电源，参数文件一键切换  
> **日期**: 2026-05-02  

---

## 1. 改造目标与设计哲学

本方案实现**双配置铁鸟台测试**：

| 模式 | 操作 | 参数文件 |
|---|---|---|
| COAX16（16电机）| 外排8个电机上电 | `COAX16_flight.param` |
| COAX8-X8（8电机）| 外排8个电机断电 | `X8_flight.param` |

**切换步骤**（仅软件，硬件断电另处理）：

```
Mission Planner → Full Parameter Tree → Load from file → [选对应 .param 文件] → Write Params → 重启飞控
```

```
M7,M8    M5,M6       M3,M4   M1,M2

M15,M16  M13,M14    M11,M12  M9,M10
```

**断电**: P1(M1,M2)、P4(M7,M8)、P5(M9,M10)、P8(M15,M16)

```
               机头 (+X)
                  ^
     P3(前左内)   |   P2(前右内)

          ────────+────────
     P7(后左内)   |   P6(后右内)
```

## 3. DroneCAN ESC_BM 机制深度解析

### 关键代码（AP_DroneCAN.cpp: SRV_send_esc）

```cpp
// _ESC_armed_mask = _esc_bm & non_zero_channels
// 只有 ESC_BM 中设置、且有非零输出的通道才激活

for (uint8_t i = esc_offset; i < max_esc_num; i++) {
    if (armed && ((1U << i) & _ESC_armed_mask)) {
        esc_msg.cmd.data[k] = scale_esc_output(i);  // 实际油门值
    } else {
        esc_msg.cmd.data[k] = 0;                     // 0 = 最低油门/无效
    }
    k++;  // k 从 0 连续增加，= i - esc_offset
}
```

**关键推论：** `cmd.data[k]` 中 k = i - esc_offset，即 **ESC硬件index = servo通道编号 - ESC_OF**

### X8 模式 CAN1 数据流验证

`ESC_OF=4, ESC_BM=3264(bits6,7,10,11)`:

| i | servo ch | bit in BM? | cmd.data[k] | 物理ESC |
|---|---|---|---|---|
| 4 | SERVO5 | ✗ | 0 | P1上桨(断电) |
| 5 | SERVO6 | ✗ | 0 | P1下桨(断电) |
| 6 | SERVO7 | **✓** | **Motor1** | P2前右内上桨 ✓ |
| 7 | SERVO8 | **✓** | **Motor2** | P2前右内下桨 ✓ |
| 8 | SERVO9 | ✗ | 0 | P5上桨(断电) |
| 9 | SERVO10 | ✗ | 0 | P5下桨(断电) |
| 10 | SERVO11 | **✓** | **Motor3** | P6后右内上桨 ✓ |
| 11 | SERVO12 | **✓** | **Motor4** | P6后右内下桨 ✓ |

### X8 模式 CAN2 数据流验证

`ESC_OF=12, ESC_BM=208896(bits12,13,16,17)`:

| i | servo ch | bit in BM? | cmd.data[k] | 物理ESC |
|---|---|---|---|---|
| 12 | SERVO13 | **✓** | **Motor5** | P3前左内上桨 ✓ |
| 13 | SERVO14 | **✓** | **Motor6** | P3前左内下桨 ✓ |
| 14 | SERVO15 | ✗ | 0 | P4上桨(断电) |
| 15 | SERVO16 | ✗ | 0 | P4下桨(断电) |
| 16 | SERVO17 | **✓** | **Motor7** | P7后左内上桨 ✓ |
| 17 | SERVO18 | **✓** | **Motor8** | P7后左内下桨 ✓ |
| - | (len=6) | - | - | P8 ESC6,7 不在数组内 ✓ |

**ESC_OF 两种模式均不变**（4 和 12），优雅地复用了原有总线布局。

### 4.2 frame_type 分发逻辑（AP_MotorsMatrix.cpp）

```cpp
case MOTOR_FRAME_TG700:
    // Q_FRAME_TYPE=0 (PLUS/COAX16): 激活原 16 电机混控
    // Q_FRAME_TYPE=1 (X/COAX8):     激活新 8 电机 X8 混控
    if (frame_type == MOTOR_FRAME_TYPE_X) {
        success = setup_motors_tg700_x8();
    } else {
        success = setup_motors_tg700();
    }
    break;
```

### 4.3 X8 混控因子（AP_MotorsMatrix_TG700.cpp）

| 因子 | 推导公式 | 数值 |
|---|---|---|
| Roll 右侧 | -(Y/Y_max) = -(1.6/1.6) | **-1.0** |
| Roll 左侧 | +(Y/Y_max) = +(1.6/1.6) | **+1.0** |
| Pitch 前 | +1.0 | **+1.0** |
| Pitch 后 | -1.0 | **-1.0** |
| Yaw CW (上桨) | -sin(5°)×arm/Y = -0.08716×2.309/1.6 | **-0.1258** |
| Yaw CCW (下桨) | +0.1258 | **+0.1258** |
| Throttle | cos(5°)×cos(2°) | **0.9956** |

arm = √(1.665²+1.6²) = √5.332 ≈ **2.309 m**

## 5. 控制逻辑严格验证

### 5.1 滚转（Roll）正确性

正 Roll 命令（向右倾）：
- Roll_factor 为正的电机**增加**推力（左侧：M5,M6,M7,M8）
- Roll_factor 为负的电机**减少**推力（右侧：M1,M2,M3,M4）
- 左侧推力 > 右侧推力 → 向右倾斜 ✓

### 5.2 俯仰（Pitch）正确性

正 Pitch 命令（抬头）：
- Pitch_factor 为正的电机增力（前排：M1,M2,M5,M6）
- Pitch_factor 为负的电机减力（后排：M3,M4,M7,M8）
- 前排推力 > 后排推力 → 机头上仰 ✓

### 5.3 偏航（Yaw）正确性

正 Yaw 命令（机头右转）：
- Yaw_factor 为正的电机增力（CCW下桨：M2,M4,M6,M8）
- Yaw_factor 为负的电机减力（CW上桨：M1,M3,M5,M7）
- CCW电机力矩反力在机体上产生顺时针方向力矩 → 机头右转 ✓

### 5.4 纯推力（Throttle）

所有8个电机 throttle_factor=0.9956 相同 → 推力对称，无寄生力矩 ✓

### 5.5 组合操纵

正Roll + 正Pitch 叠加验证：

| Motor | Roll | Pitch | 合力方向 | 位置 |
|---|---|---|---|---|
| M1(右前上) | -1.0 | +1.0 | 0（相消） | 右前 |
| M2(右前下) | -1.0 | +1.0 | 0 | 右前 |
| M3(右后上) | -1.0 | -1.0 | -2（最减） | 右后 |
| M4(右后下) | -1.0 | -1.0 | -2 | 右后 |
| M5(左前上) | +1.0 | +1.0 | +2（最增） | 左前 |
| M6(左前下) | +1.0 | +1.0 | +2 | 左前 |
| M7(左后上) | +1.0 | -1.0 | 0 | 左后 |
| M8(左后下) | +1.0 | -1.0 | 0 | 左后 |

右后最减，左前最增 = 标准四旋翼组合操纵行为 ✓

### 5.6 DroneCAN 命令数据流

已通过阅读 `AP_DroneCAN.cpp:SRV_send_esc()` 源码逐行验证（见第3节）：
- 非连续 ESC_BM 在代码逻辑中完全等价，无间隙越界风险 ✓
- 断电 ESC 槽位精确填0，不会意外触发任何控制 ✓

## 7. 一键模式切换流程

### 切换到 X8 模式（断外排电）

```
Step 1: 断开外排8个电机（P1/P4/P5/P8）的 PDU 支路电源
Step 2: Mission Planner → Full Parameter Tree
        → Load from file → docs/X8_flight.param
        → Write Params
Step 3: 重启飞控
Step 4: 验证 Q_FRAME_TYPE=1, Q_M_THST_HOVER=0.50
Step 5: 执行水平校准 (Level Horizon)
Step 6: 执行 X8 电机测试（验证8个电机响应）
```

### 切回 COAX16 模式（恢复外排电）

```
Step 1: 恢复外排8个电机 PDU 电源
Step 2: Mission Planner → Full Parameter Tree
        → Load from file → docs/COAX16_flight.param
        → Write Params
Step 3: 重启飞控
Step 4: 验证 Q_FRAME_TYPE=0, Q_M_THST_HOVER=0.25
Step 5: 执行水平校准
Step 6: 执行全16电机测试
```

## 9. 首飞参数调整建议

### 偏航权威不足时

```
Q_A_RAT_YAW_P   0.40 → 0.50~0.60
Q_A_RAT_YAW_I   0.04 → 0.05~0.06
Q_A_ANG_YAW_P   2.0  → 2.5~3.0
```

### 悬停油门精调

开启 `Q_M_HOVER_LEARN,1`，完成3-5次起降后，读取 `Q_M_THST_HOVER` 学习值。

### PID 震荡排查

若 Roll/Pitch 出现高频震荡（>5Hz）：
```
Q_A_RAT_RLL_P   0.10 → 0.07
Q_A_RAT_RLL_D   0.003 → 0.002
Q_A_RAT_PIT_P   0.10 → 0.07
Q_A_RAT_PIT_D   0.003 → 0.002
```
