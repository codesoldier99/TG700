# TG700 同轴X8 改造方案

> **机型**: ZeroOne M9 飞控 · TG700 骨架  
> **目标**: 去掉外排8个电机，保留内排4个吊舱（共8电机）组成同轴X8构型  
> **日期**: 2026-05-02  

---

## 1. 改造前后对比

### 原 COAX16 布局（16电机）

```
              机头 (+X)
                ^
P4(L-外) P3(L-内)   P2(R-内) P1(R-外)   ← 前排
M7,M8   M5,M6       M3,M4   M1,M2
                |
P8(L-外) P7(L-内)   P6(R-内) P5(R-外)   ← 后排
M15,M16  M13,M14    M11,M12  M9,M10
```

| 参数 | COAX16 |
|---|---|
| 电机数 | 16 |
| 吊舱数 | 8 (4内+4外) |
| CAN1 ESC数 | 8 (P1,P2,P5,P6) |
| CAN2 ESC数 | 8 (P3,P4,P7,P8) |
| 外排臂长 Y | ±3.4 m |
| 内排臂长 Y | ±1.6 m |

### 改造后 COAX8 (X8) 布局（8电机）

**拆除**: P1(M1,M2)、P4(M7,M8)、P5(M9,M10)、P8(M15,M16) 外排共8个电机  
**保留**: P2(前右内)、P3(前左内)、P6(后右内)、P7(后左内) 内排共8个电机

```
              机头 (+X)
                ^
    P3(前左内)  |  P2(前右内)
    M5(上CW)    |  M1(上CW)
    M6(下CCW)   |  M2(下CCW)
           ─────+─────
    P7(后左内)  |  P6(后右内)
    M7(上CW)    |  M3(上CW)
    M8(下CCW)   |  M4(下CCW)
```

| 参数 | COAX8 (X8) |
|---|---|
| 电机数 | 8 |
| 吊舱数 | 4 (全内排) |
| CAN1 ESC数 | 4 (P2前右内 + P6后右内) |
| CAN2 ESC数 | 4 (P3前左内 + P7后左内) |
| 臂长 Y | ±1.6 m |
| 臂长 X | ±1.665 m |

## 2. ESC 硬件重新配置（关键前提）

### 背景

DroneCAN RawCommand 通过数组**索引**（ESC channel index）寻址各电调，  
与 DroneCAN 节点ID无关。  
原16电机中，各吊舱的 ESC channel index 分配如下：

| CAN1 吊舱 | 原 channel index | 保留？ |
|---|---|---|
| P1 (前右外) | 0, 1 | **拆除** |
| P2 (前右内) | 2, 3 | **保留** |
| P5 (后右外) | 4, 5 | **拆除** |
| P6 (后右内) | 6, 7 | **保留** |

| CAN2 吊舱 | 原 channel index | 保留？ |
|---|---|---|
| P3 (前左内) | 0, 1 | **保留** |
| P4 (前左外) | 2, 3 | **拆除** |
| P7 (后左内) | 4, 5 | **保留** |
| P8 (后左外) | 6, 7 | **拆除** |

### 操作要求

**必须重新烧写 ESC channel index**，使剩余8个电调紧密排列在0-3：

| 吊舱 | CAN总线 | 电机 | 新 channel index |
|---|---|---|---|
| P2 前右内 上桨 (CW) | CAN1 | M1 | **0** |
| P2 前右内 下桨 (CCW) | CAN1 | M2 | **1** |
| P6 后右内 上桨 (CW) | CAN1 | M3 | **2** |
| P6 后右内 下桨 (CCW) | CAN1 | M4 | **3** |
| P3 前左内 上桨 (CW) | CAN2 | M5 | **0** |
| P3 前左内 下桨 (CCW) | CAN2 | M6 | **1** |
| P7 后左内 上桨 (CW) | CAN2 | M7 | **2** |
| P7 后左内 下桨 (CCW) | CAN2 | M8 | **3** |

> **操作方法**: 使用 Mission Planner → DroneCAN → 选中对应 ESC 节点 → 修改 `esc_index` 参数并保存。  
> 或使用弦动电调专用配置工具（参考《弦动电调CAN通信协议.pdf》）。

### 3.1 AP_MotorsMatrix.h（第 171 行）

```cpp

bool setup_motors_tg700();

// 改后（新增一行）:
bool setup_motors_tg700();

```

### 3.2 AP_MotorsMatrix_TG700.cpp（末尾追加）

新增 `setup_motors_tg700_x8()` 函数，混控因子如下：

| 因子 | 计算依据 | 数值 |
|---|---|---|
| Roll（右侧）| -(Y/Y_max) = -(1.6/1.6) | **-1.0** |
| Roll（左侧）| +(Y/Y_max) = +(1.6/1.6) | **+1.0** |
| Pitch（前）| +1.0 | **+1.0** |
| Pitch（后）| -1.0 | **-1.0** |
| Yaw（上CW）| -sin(5°)×arm/Y_max = -0.08716×2.309/1.6 | **-0.1258** |
| Yaw（下CCW）| +0.1258 | **+0.1258** |
| Throttle | cos(5°)×cos(2°) | **0.9956** |

其中 arm = √(1.665² + 1.6²) = √5.332 ≈ **2.309 m**

Motor → SERVO → CAN 路由：

```
M1(上CW)  → SERVO5  (func33) → CAN1 ESC0 → P2前右内
M2(下CCW) → SERVO6  (func34) → CAN1 ESC1 → P2前右内
M3(上CW)  → SERVO7  (func35) → CAN1 ESC2 → P6后右内
M4(下CCW) → SERVO8  (func36) → CAN1 ESC3 → P6后右内
M5(上CW)  → SERVO9  (func37) → CAN2 ESC0 → P3前左内
M6(下CCW) → SERVO10 (func38) → CAN2 ESC1 → P3前左内
M7(上CW)  → SERVO11 (func39) → CAN2 ESC2 → P7后左内
M8(下CCW) → SERVO12 (func40) → CAN2 ESC3 → P7后左内
```

### 3.3 AP_MotorsMatrix.cpp（第 1335-1339 行）

```cpp
// 原代码:
#if AP_MOTORS_FRAME_TG700_ENABLED
    case MOTOR_FRAME_TG700:
        success = setup_motors_tg700();
        break;
 #endif

// 改后:
#if AP_MOTORS_FRAME_TG700_ENABLED

        // frame_type=1 (X/COAX8):      8电机X8内排

            success = setup_motors_tg700();
        }
        break;
 #endif
```

## 4. 编译指南

### 环境准备

```bash
# 克隆后首次需初始化子模块
git submodule update --init --recursive

# 配置 Python 环境
python3 -m venv venv && source venv/bin/activate
pip install empy pexpect
```

### 编译 ArduPlane for ZeroOneM9

```bash
cd /path/to/TG700

# 配置目标板
./waf configure --board ZeroOneM9

# 编译 ArduPlane（含 TG700 电机混控）
./waf plane

# 输出固件路径:
# build/ZeroOneM9/bin/arduplane.apj
```

| 参数 | 说明 |
|---|---|

通过 Mission Planner → 固件安装 → 选择自定义固件 → 选中 `arduplane.apj`

## 5. 参数配置

参数文件: `docs/X8_flight.param`（可直接通过 Mission Planner 加载）

### 关键参数速查表

| 参数 | COAX16 原值 | X8 新值 | 说明 |
|---|---|---|---|
| `Q_FRAME_CLASS` | 18 | **18** | 不变，仍用TG700机架类 |
| `Q_FRAME_TYPE` | 0 | **1** | 0=COAX16, 1=COAX8 |
| `CAN_D1_UC_ESC_BM` | 4080 | **240** | bits4-7，4个ESC |
| `CAN_D1_UC_ESC_OF` | 4 | **4** | 从SERVO5开始，不变 |
| `CAN_D2_UC_ESC_BM` | 1044480 | **3840** | bits8-11，4个ESC |
| `CAN_D2_UC_ESC_OF` | 12 | **8** | 从SERVO9开始（原为13） |
| `SERVO5-8_FUNCTION` | 33-36 | **33-36** | CAN1 Motor1-4，不变 |
| `SERVO9-12_FUNCTION` | 82-85 | **37-40** | CAN2 Motor5-8（原为CAN1后排）|
| `SERVO13-20_FUNCTION` | 37-163 | **0** | 全部停用 |
| `Q_M_THST_HOVER` | 0.25 | **0.50** | 电机少一半，悬停油门翻倍 |
| `Q_M_HOVER_LEARN` | 0 | **1** | 飞行中自动学习 |
| `BATT_ESC_MASK` | 0(全部) | **255** | 仅监控8个ESC |
| `Q_A_RAT_YAW_P` | 0.30 | **0.40** | 偏航权威降低，P适当提高 |

### ESC_BM 计算说明

```
CAN1: SERVO5,6,7,8 → ch4,5,6,7 → bit mask = 0b11110000 = 0x00F0 = 240
CAN2: SERVO9,10,11,12 → ch8,9,10,11 → bit mask = 0b111100000000 = 0x0F00 = 3840
```

## 6. 上电配置流程

### 步骤一：烧写固件

1. 用 Mission Planner 烧写编译好的 X8 固件
2. 固件烧写完成后不要急于配置参数

### 步骤二：重新配置 ESC channel index

按第 2 节的表格，依次对 P2、P6（CAN1）和 P3、P7（CAN2）的8个电调重新配置 channel index。

> 可在 Mission Planner → DroneCAN → ESC → 查找各节点并修改 `esc_index`

### 步骤三：加载 X8 参数

```
Mission Planner → CONFIG → Full Parameter Tree → Load from file → X8_flight.param → Write Params
```

加载后重启飞控。

### 步骤四：传感器校准

按顺序完成以下校准（**加载参数后必须重新做**）：

- [ ] 加速度计六面校准
- [ ] 陀螺仪校准
- [ ] 水平校准（Level Horizon）
- [ ] RC 遥控校准

### 步骤五：电机测试

通过 Mission Planner → 电机测试，逐一验证8个电机：

| 测试项 | 预期 |
|---|---|
| Motor1（SERVO5）| P2前右内 上桨旋转 |
| Motor2（SERVO6）| P2前右内 下桨旋转（反向）|
| Motor3（SERVO7）| P6后右内 上桨旋转 |
| Motor4（SERVO8）| P6后右内 下桨旋转（反向）|
| Motor5（SERVO9）| P3前左内 上桨旋转 |
| Motor6（SERVO10）| P3前左内 下桨旋转（反向）|
| Motor7（SERVO11）| P7后左内 上桨旋转 |
| Motor8（SERVO12）| P7后左内 下桨旋转（反向）|

> 若某电机不转或转速异常，首先检查 ESC channel index 配置和 SERVO_FUNCTION 赋值。

### 步骤六：地面联调确认

```
Mission Planner → Status → 查看 Q_FRAME_TYPE 显示为 1
               → 查看 motor1-8 均有输出
               → 倾斜机体，验证 Roll/Pitch 姿态响应正确
```

## 7. 首飞参数调整建议

### 悬停油门学习

首飞前 `Q_M_THST_HOVER,0.50` 为估算值。  
设置 `Q_M_HOVER_LEARN,1` 后，飞控会在 QHOVER 模式下自动学习，  
5~10次起降后读取实际学习值并写入。

### 偏航权威验证

X8 偏航仅依赖内排电机的切向倾斜产生力矩，权威比 COAX16 弱。  
悬停中若偏航响应不足（慢于预期）：

```
Q_A_RAT_YAW_P   0.40 → 0.50~0.60
Q_A_RAT_YAW_I   0.04 → 0.05~0.06
```

### Roll/Pitch PID

X8 力臂（±1.6m）与 COAX16 内排（±1.6m）相同，初始增益继承 v2 lightload。  
若出现震荡则降低 P/D，若响应迟钝则提高。

## 8. 注意事项

1. **ESC channel index 重新配置是必要条件**，不配置则 RawCommand 数组索引错误，电机无响应或错位控制。

2. **SERVO13-20 必须设为 0**（已在参数文件中设置），否则飞控仍会尝试向已拆除的 ESC 发送命令，干扰 CAN 总线。

3. **CAN_D2_UC_ESC_OF 从 12 变为 8**：X8 中 CAN2 从 SERVO9 开始（channel index 8），原 COAX16 从 SERVO13 开始（channel index 12），需确认参数写入正确。

4. **ESC_BM 必须精确匹配**：BM（bitmask）决定飞控向该 CAN 总线发送哪几个命令槽，多余的槽发 0 会触发电调超时保护。

5. **首飞使用铁鸟台**，保留人工急停手段（PDU 红色按钮），直至 QHOVER 悬停稳定 ≥30 秒。
