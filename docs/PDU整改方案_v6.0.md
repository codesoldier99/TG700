## 摘要

本方案系统性地对 PDU v5.0 设计进行点评，提出 v6.0 的整改路线图。
核心结论：**v5.0 设计理念正确（双极断开、预充、急停），
但安全规范层面存在 6 项关键缺失**，必须按 P0 整改后才能在
800V 满压下投入使用。

### 1.4 关键数据复算（基于弦动技术回复）

负载电容：
- 单 ESC 输入电容：**170 ?F**
- 16 ESC 并联：**C_total = 2.72 mF**

预充时间常数（100Ω 电阻下）：
- τ = R × C = 100 × 2.72mF = **272 ms**
- 5τ（充到 99%）= **1.36 秒**
- 7τ（充到 99.9%）= **1.9 秒**

**这意味着 v5.0 设计的 15 秒预充对实际负载是过度设计 11 倍。**
但同时也暴露了一个新问题：

预充能量：
- E = ?CV? = 0.5 × 2.72mF × 800? = **870 J**
- 100W 电阻在 1τ 内吸收 ≈ 870/0.272 = **3200W 平均**（32 倍额定）
- **现有 100Ω/100W 电阻处于热瞬态曲线边缘**，长期使用有过热风险

## 3. Phase 1 (P0) 详细整改

### 3.1 H-1: 预充电压反馈 + 时间超时双判据

**问题**：当前仅靠 KT 时间继电器 15 秒切换，遇到电容故障/电阻烧断时仍会硬合闸。

**整改**：
- 增加 **DC 电压继电器**（如 ABB CM-ESS.1、AcromAg、JVR-52 等）
- 接到 KM1/KM2 后端（负载侧）
- 设定动作阈值 = **0.95 × V_输入**
- 判据：电压达到 95% **或** 20 秒超时报警，**两者满足任一才允许合主接触器**

```
                 输入端 800V
                     │
          ┌──[FU1]──┴──[KM1主]──┬──→ 输出端 +
          │                       │
          ├──[KM3预充]──[R1]──────┤  ← 电压继电器在这里采样
          │                       │
          │           ┌──[V继电器]┘
          │           │
          │      继电器触点 → 控制 24V 回路
          │
          └──[KM2主]──────────────→ 输出端 ?
```

**控制逻辑变化**（替换原 KT-1/KT-2 逻辑）：
```
按下启动 → KA1 自锁 → KM3 吸合（预充开始）
        ↓
    电压继电器持续监测母线电压
        ↓
   ┌─── 电压达到 95% (典型 1-2 秒，最快 0.7s) ──→ KM3 断 → KM1+KM2 合 ?
   │
   └─── 20 秒超时未达到 95% ──→ 急停 + 面板"预充失败"红灯 ?
```

**物料**：
- DC 电压继电器: 约 ?300-800
- 接线/调试: 0.5 工时

### 3.2 H-2: 续流二极管全数补齐

**问题**：所有 24V 直流线圈断开瞬间产生反电动势（数百伏级），会击穿 PLC/电子开关输入。

**整改**：每个 24V 线圈两端**反向并联** 1N4007（或 SMB 方向快恢复）：
- KM1 线圈（EV200 #1）
- KM2 线圈（EV200 #2）
- KM3 线圈（HFE80V-40）
- KA1 线圈（中间继电器）
- KT 线圈（H3Y-2 时间继电器）
- 任何新增的 KM4（放电）线圈

**接线规范**（极性别接反）：
```
   24V (+) ─────┬──── 线圈 + ─── 24V (-)
                │
                ▼ 二极管阳极
               1N4007
                ▲ 二极管阴极
                │
   24V (+) ─────┴────────────────
   (阴极接 +24V，阳极接线圈端，使二极管反向偏置)
```

**物料**：
- 1N4007 × 5（备 2）= 约 ?10
- 接线: 0.5 工时

### 3.3 H-3: 加装 DC 绝缘监测装置（IMD）

**问题**：直流系统不能用交流漏电断路器，必须用专用 IMD。
800V DC 系统是 ECE R100、GB/T 18384 强制要求。

**整改**：在 PDU 输入端 + / ? 与 PE 之间加装 **Bender IR-155-3204** 或国产替代。

```
输入端 + ────┬───→ PDU 主回路
             │
            [IMD 正极采样]
             │
             ├──→ 内部测量电路（高阻抗）
             │
            [IMD 负极采样]
             │
输入端 ? ────┴───→ PDU 主回路
             │
            [PE 接地]
```

**报警接入**：IMD 故障继电器触点串入 24V 急停回路 → 绝缘故障时自动急停。

**阈值设定**：
- 警告：100 Ω/V × 800V = 80 kΩ
- 跳闸：50 Ω/V × 800V = 40 kΩ

**物料**：
- Bender IR-155-3204: 约 ?2000-3000
- 国产替代（卓一、永华）: 约 ?800-1500
- 安装/调试: 1 工时

### 3.4 H-4: 预充→主接触器切换死区

**问题**：当前 KT-1（NC 延时断开）和 KT-2（NO 延时闭合）同时动作，
理论上可能出现"瞬间预充和主接触器同时通"或"瞬间全断"。

**整改**：把 KT 拆为两级时序：
- KT_A：T1 时刻断开 KM3 触点
- KT_B：T2 = T1 + 100ms 时刻闭合 KM1/KM2 触点

或用一个**带死区设定的工业级安全时间继电器**（Phoenix Contact ETD 系列、Pilz S1WP 等）。

**最简实现**：用现有 H3Y-2 + 一个新增的中间时间继电器 KT2（10ms-100ms 可调）

```
原电压继电器触发
        ↓
    KT-1 触点 → 立即断开 KM3
        ↓
    KT2 计时 100ms
        ↓
    KT2 触点 → 闭合 KM1+KM2
```

**物料**：
- 中间时间继电器（小型、0-1s 可调）: 约 ?150
- 接线: 0.5 工时

### 3.5 H-6: 急停升级为双通道

**问题**：单通道急停按钮触点粘连或线路对地短路时会"虚急停"。

**整改**：
- 急停按钮换为**双触点版本**（NC + NC，两组独立触点）
- 加装**安全继电器**（Pilz PNOZ X1、SICK UE410、施克 UE10 等）
- 急停硬线**同时接到陆科电源的"外部急停"输入**，让电源也同步停

**联锁框图**：
```
   ┌───────────────────────────────────┐
   │ 急停按钮（双 NC 触点）            │
   │   触点 A ───┐    触点 B ───┐      │
   └─────────────┼────────────────┼─────┘
                 ↓                ↓
        ┌──── 安全继电器 PNOZ X1 ────┐
        │ (双通道交叉监测)            │
        └───┬──────────┬───────────────┘
            │          │
     PDU 内部急停回路   陆科电源 ESTOP 端子
            │          │
       (KM1+KM2 断)  (整流停机)
```

**物料**：
- 双触点蘑菇急停按钮: 约 ?150
- 安全继电器 Pilz PNOZ X1: 约 ?1500（可用国产替代 ?400）
- 接线/调试: 1 工时

### 3.6 H-13: Retrofit 第二只 EV200 复核

**问题**：根据您反馈，第二只 EV200 是后加装的。retrofit 易引入：
- 24V 控制电源容量不足（多一个线圈多 1.6A 吸合峰值）
- KT-2 触点电流过载（Omron H3Y-2 DC 容量仅 1-2A）
- 续流二极管漏装
- 两只 EV200 同步吸合时间差（机械公差导致）

**整改 / 复核清单**：

| 检查项 | 期望值 | 不合格的处理 |
|:-|:-|:-|
| 24V 开关电源额定电流 | ≥ 5A | 换成 10A 级 |
| 两只 EV200 线圈接线方式 | **并联**到同一组触点 | 串联是错的，必须改并联 |
| 每只 EV200 线圈续流二极管 | 都装好 | 见 H-2 |
| KT-2 触点电流 | ≤ 触点容量 | **必须加中间继电器扩流**（Omron MY2N） |
| 两只 EV200 同步吸合时间差 | < 5 ms | 用示波器双通道测量 |
| EV200 主触点接线极性 | 按厂家手册 | 装反会降低灭弧能力 |
| EV200 安装牢固度 | M6×4 螺栓 + 防松胶 | 振动会松动 |
| 爬电距离 / 空气间隙 | ≥ 12.5mm / 8mm（IEC 60664） | 用塞规测量 |

**特别警告**：当前 KT-2 触点容量 5A AC 250V，对应 DC 24V 感性负载约 1A。
原来驱动 1 只线圈（~130mA 稳态、1.6A 吸合）勉强可以；
**现在驱动 2 只线圈峰值 3.2A，长期会烧蚀触点最终焊死**。

**强烈建议**：插入一级**中间继电器**做扩流：

```
KT-2 (5A 触点) → 中间继电器 (Omron MY2N, 10A 触点) → 两只 EV200 线圈并联
                                                       ↓
                                            每只线圈各并 1N4007 续流
```

**物料**：
- Omron MY2N + 底座: 约 ?80
- 接线/调试: 0.5 工时

## 4. Phase 2 (P1) 详细整改

### 4.1 H-5: 熔断器扩容（仅限需要 500kW 输出场景）

**说明**：如果铁鸟台测试不需要满 500kW（200kg 测试用 < 100kW，700kg 用 ~300kW），
可以暂不升级 FU1。但 200kg 测试通过、转 700kg 测试前必须做。

**整改**：
- 单组方案：FU1 升级为 **630A / 1000V DC**（Bussmann FWP-630A）
- 双组并联：保留现 400A，并联一组 400A，整体 800A（备用方案）

**物料**：
- 630A DC 熔断器（gPV 型）: 约 ?800
- 安装: 0.5 工时

### 4.2 电阻升级 100W → 200W（必做）

**问题**：基于 870J 能量，100W 电阻处于瞬态边缘。

**整改**：
- 维持 100Ω 阻值（τ 已经够快）
- 把功率从 100W 升级到 **200W 铝壳电阻**（如瑞士 RXG24-200W）

或如果想缩短预充时间：
- 升级为 **50Ω / 200W**（厂家弦动推荐值）

**物料**：
- 100Ω/200W 铝壳电阻: 约 ?150
- 接线（旧电阻替换）: 0.5 工时

### 4.3 H-7: 控制回路与主回路分槽

**整改**：
- 主回路（橙色 50mm?）和控制回路（24V 红黑细线）**分别走金属线槽**
- 间距 ≥ 50mm（IEC 61439 推荐）
- 不能分槽时，控制线束加**金属编织屏蔽管**，单端接 PE
- 柜内可加**绝缘隔板**

**物料**：
- 线槽 + 屏蔽管: 约 ?200
- 重新整理布线: 2 工时

### 4.4 H-8: 泄能放电回路

**问题**：主接触器断开后，母线电容上的能量保持高压数分钟，维护时危险。

**整改**：增加 KM4 + R2，跨接正负母线：

```
正母线 ●─┬──[KM1主]──→ 输出 +
        │
        │   (停机时 KM4 自动吸合放电)
        │
       [KM4 (NO)]
        │
       [R2 (50Ω/5kW 铝壳)]
        │
       [KM4]
        │
        │
        ├──[KM2主]──→ 输出 ?
        │
负母线 ●─┘
```

**控制逻辑**：
- 工作时（KA1 已自锁）：KM4 断开
- 停机/急停时（KA1 释放）：KM4 吸合，泄能
- 放电完成后（电压 < 50V，由 V 继电器二号判定）：KM4 断开

**放电时间估算**：τ = 50×2.72mF = 136ms，5τ = 0.68s，所以**1 秒放电完毕**。
能量 870J 在 50Ω 上 1 秒内消耗 → 平均功率 870W → 5kW 电阻完全胜任。

**物料**：
- 50Ω/5kW 铝壳电阻: 约 ?500
- HFE80V-40 继电器（KM4）: 约 ?200
- 第二个 V 继电器（放电完成判定）: 约 ?200
- 接线: 1 工时

### 4.5 H-9: 负极熔断器 FU2

**问题**：直流系统单极保护不充分，正极对地短路时电流可能绕过 FU1。

**整改**：在 KM2 之前（输入侧）增加 FU2，规格与 FU1 完全一致。

```
输入端 + ●──[FU1 400A]──[KM1]──→ 输出端 +
输入端 ? ●──[FU2 400A]──[KM2]──→ 输出端 ?  ← 新增 FU2
```

**物料**：
- 400A/1000V DC 熔断器: 约 ?400
- 熔断器底座: 约 ?150
- 接线: 0.5 工时

### 4.6 H-12: PE 汇流排 + 柜门接地

**整改**：
- 柜内底部加 30×5mm 紫铜 PE 汇流排
- 所有金属外壳（继电器外壳、柜体、面板）软铜带接到 PE 排
- 柜门用软编织铜线（25mm? 起）接到柜体
- 接地电阻 ≤ 4Ω（陆科电源说明书强制要求）

**物料**：
- 紫铜 PE 排（30×5×500mm）: 约 ?80
- 软编织铜线 25mm? × 2m: 约 ?100
- M6 接地螺栓 × 10: 约 ?30
- 接线/钻孔: 1 工时

## 5. Phase 3 (P2) 长期完善（视需求选做）

### 5.1 制动 Chopper

**目的**：吸收电机回馈能量，防止母线过压。

**实现**：IGBT + 制动电阻 + 快恢复二极管

参考：西门子 G120 制动单元 / 国产电机驱动用制动单元

**触发**：母线电压 > 870V → IGBT 导通 → 能量泄放到电阻

**物料预算**: ?3000-5000

### 5.2 MOV/TVS 浪涌抑制

**目的**：吸收瞬态浪涌，保护下游 ESC。

**位置**：跨接在 PDU 输出端 + / ? 之间

## 7. 整改后的控制时序图（v6.0）

```
┌─────────────────────────────────────────────────────────────────┐
│                    V6.0 PDU 启停时序                             │
└─────────────────────────────────────────────────────────────────┘

启动流程：
T=0       按下 SB3 启动按钮
          ↓
T=10ms    KA1 自锁
          KM3 吸合（预充开始）
          ↓
T=10ms~   电压继电器持续监测
          ↓
T=~700ms  电压达到 95% × V_输入
          ↓ (电压继电器触发)
T=~700ms  KM3 断开
          ↓ (中间时间继电器 KT2 计时 100ms)
T=~800ms  KM1+KM2 同步吸合
          ↓
T=~800ms+ 进入正常工作状态

异常路径：
  - 20 秒超时未达到 95% → 急停 + 红灯告警
  - 绝缘电阻跌至 < 40 kΩ → IMD 触发急停
  - 任何急停按钮按下（双通道安全继电器） → KM1+KM2 立即断开 + KM4 吸合放电

停机流程：
T=0       按下 SB2 停止 / 急停 / 绝缘故障 / 系统故障
          ↓
T=10ms    KA1 释放
          KM1+KM2 断开（主回路切断）
          KM4 吸合（放电回路连通）
          ↓ (R2 = 50Ω, τ=136ms)
T=~700ms  母线电压跌至 50V 以下
          ↓ (V 继电器#2 触发)
T=~800ms  KM4 断开（放电完成）
          ↓
T=~800ms+ 完全断电安全状态
```

## 8. 整改后验收清单

施工完成后必须按以下清单逐项验收：

### 8.1 静态检查（断电状态）

- [ ] 所有 24V 线圈两端续流二极管正确并联（极性正确）
- [ ] 万用表 Ω 档：电压继电器反馈线接到 KM1/KM2 输出侧
- [ ] 万用表 Ω 档：负极熔断器 FU2 已串入负极路径
- [ ] PE 汇流排已接所有金属外壳，对地电阻 ≤ 4Ω
- [ ] 主回路与控制回路分槽，间距 ≥ 50mm
- [ ] 双触点急停按钮接到安全继电器
- [ ] 急停硬线同时接陆科电源外部急停输入
- [ ] 力矩扳手复核：M10 主回路 30 N·m，M8 25 N·m
- [ ] 所有线缆铜鼻已热缩管覆盖

### 8.2 24V 控制回路功能测试（不带主电源）

- [ ] 按下启动 → KM3 吸合（听响）
- [ ] 等待 1-2 秒 → KM3 断开 + KM1+KM2 同步吸合
- [ ] 用示波器测两只 EV200 同步时间差 < 5ms
- [ ] 按下停止 → KM1+KM2 立即断开 + KM4 吸合
- [ ] 等待约 1 秒 → KM4 断开
- [ ] 任何状态按急停 → 所有接触器立即释放

### 8.3 低压全功能测试（陆科 100V 输出）

- [ ] 按启动 → 电压表读数从 0 平稳爬升到 95V
- [ ] 电压继电器在约 95V 触发 → KM1+KM2 合
- [ ] 用红外测温枪测 R1 温度，最高 < 80°C
- [ ] 测预充期间 R1 上的实际电流 = V/R = 0.95A（理论）
- [ ] 按急停 → 电压表显示从 95V 跌至 < 5V，时间 < 1 秒
- [ ] IMD 显示绝缘电阻正常（应 > 1MΩ）
- [ ] 模拟绝缘故障（短接正极到 PE 通过 50kΩ）→ IMD 报警

### 8.4 800V 满压测试（仅前序通过后）

- [ ] 按启动 → 电压平稳爬升到 760V（95%）
- [ ] 切换主接触器，无跳火 / 异响
- [ ] 母线电压稳定在 800V ± 5V
- [ ] R1 温度 < 100°C（红外测温）
- [ ] 母线静态电流 < 10mA（漏电指标）
- [ ] 急停响应时间 < 100ms
- [ ] 急停后 1 秒内母线电压 < 50V

## 11. 与其他方案的兼容性

本整改方案**不破坏 v5.0 设计的核心逻辑**，是**增量升级**：

- 保留：双极断开 EV200×2、KM3 预充、急停硬切断、24V 独立控制、所有标签和保护套
- 升级：100W 电阻 → 200W、单通道急停 → 双通道、单极熔断 → 双极、时间判据 → 电压判据
- 新增：IMD、放电回路、续流二极管、中间扩流继电器、PE 汇流排

**对陆科电源、铁鸟台架、飞机本体均不影响**，可在不停机条件下分阶段施工。
