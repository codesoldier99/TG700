## 六、关键问题（阻止下次飞行的问题）

### 🔴 问题1：DroneCAN 节点 ID 冲突（严重）

```
MSG: PreArm: DroneCAN: Duplicate Node ESC../2!
MSG: PreArm: DroneCAN: Duplicate Node ESC../4!
```

**现象**：解锁 → 上锁后尝试再次解锁时，系统报告节点 ID 2 和节点 ID 4 存在重复。

**影响**：同一 CAN 总线上两个 ESC 共享同一节点 ID，飞控无法独立寻址，相应电机将收到相同指令或不被控制，**直接导致控制失效和飞机失稳**。

**根本原因分析**：
- CAN 自动节点分配（DNA）协议在 ESC 上电重启后产生冲突
- 或物理上两个 ESC 被烧录了相同的首选节点 ID

**解决方案**：
1. 使用 UAVCAN GUI Tool 或 DroneCAN 节点调试工具逐一检查所有 16 个 ESC 的节点 ID
2. 为每个 ESC 手动配置唯一节点 ID（建议 CAN1: 1-8，CAN2: 9-16 或其他不冲突范围）
3. 固化节点 ID 配置（非动态分配），避免每次上电重新分配
4. **在此问题解决前，禁止进行任何飞行测试**

---

### 🔴 问题2：罗盘未校准（严重）

```
MSG: PreArm: Compass not calibrated
```

**影响**：
- 偏航姿态参考不准确，AutoMode 下无法可靠导航
- EKF 偏航漂移，长时间悬停无法保持航向
- 影响 QSTABILIZE 模式的磁场补偿精度

**解决方案**：
1. 在开阔无金属干扰区域，通过地面站（Mission Planner / QGC）执行标准罗盘校准
2. 建议在安装螺旋桨前完成校准以消除电机干扰
3. 校准后执行 `COMPASS_MOT` 电机干扰补偿

---

### 🔴 问题3：AHRS 类型不匹配（严重）

```
MSG: PreArm: AHRS: not using configured AHRS type
MSG: PreArm: AHRS: waiting for home
```

**分析**：`AHRS_EKF_TYPE=3`（EKF3），但系统报告未使用配置的 AHRS 类型。  
可能原因：EKF3 初始化条件未满足（无 GPS、无罗盘校准）。

**解决方案**：
1. 先解决罗盘校准和 GPS 问题
2. 在空旷场地上电，等待 EKF3 收敛后再尝试解锁
3. 若需要纯 IMU 悬停，可临时将 `AHRS_EKF_TYPE=2` 进行非 GPS 测试（不推荐用于实际飞行）

## 七、需关注的警告（不阻止飞行，但需评估）

### 🟡 警告1：加速度计偏置偏大

IMU0 Y 轴加速度计偏置 +0.220g，IMU2 Y 轴 +0.199g（约 2 m/s²）。  
标准建议值 < 1 m/s²。  
**建议**：重新执行加速度计校准（六面校准），检查飞控安装平整度。

### 🟡 警告2：悬停油门固定值

`Q_M_THST_HOVER=0.35`（固定），`Q_M_HOVER_LEARN=2`（自动学习）已启用，但本次地面测试无螺旋桨，学习值为 NaN，**首飞时悬停油门需要人工调整或充分学习**。

**建议**：首次系留飞行时，先设 `Q_M_HOVER_LEARN=0` 手动确定悬停油门后再开启自动学习。

### 🟡 警告3：SERVO17-20 默认值非标准

```
PARM: SERVO17_FUNCTION=160  default=-1
PARM: SERVO18_FUNCTION=161  default=-1
PARM: SERVO19_FUNCTION=162  default=-1
PARM: SERVO20_FUNCTION=163  default=-1
```

函数 160-163 为非标准电机映射，固件 patch 生效。需确认固件升级不会重置这些值。  
**建议**：将关键参数持久化并在版本升级后验证。

### 🟡 警告4：Yaw 控制权能不足（理论预测）

如[代码分析报告](#)所述，Yaw 因子（0.0971）基于几何力臂估算，若实物 Yaw 依赖纯反扭矩，实际 Yaw 权能可能被高估 2-5 倍。  
**建议**：系留飞行时专项测试 Yaw 指令响应速度，若 Yaw 响应迟钝，调整 `Q_A_RAT_YAW_P`（当前 0.18）和 Yaw 因子。
