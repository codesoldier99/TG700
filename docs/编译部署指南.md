# TG700 编译部署指南

> 适用环境: DMIT 云主机（Ubuntu 20.04/22.04）  
> 目标固件: ArduPlane for ZeroOne M9  
> 分支: `claude/adapt-x8-coaxial-drone-BzNg0`  

---

## 1. Git 分支策略建议

### 当前建议：**留在当前分支，不合并到 main**

| 场景 | 建议操作 |
|---|---|
| 铁鸟台测试前 | 继续在 `claude/adapt-x8-coaxial-drone-BzNg0` 上开发 |
| 铁鸟台测试通过 | 创建 PR → 代码审查 → 合并到 `main` |
| 飞行测试通过 | 打 `release` 标签 |

**不急于合并到 main 的原因**：
1. X8 混控参数（PID、THST_HOVER）尚未通过飞行验证
2. 一旦合并 main 即为"生产代码"，出问题需要 hotfix
3. 分支可随时切回 main 编译旧固件对比

### 合并时机的判断条件

- [ ] X8 模式铁鸟台悬停稳定 ≥30 秒
- [ ] COAX16 模式在同一铁鸟台通过回归测试
- [ ] `Q_M_THST_HOVER` 学习值稳定（±0.03 以内）
- [ ] 偏航响应正常（无明显慢响应或震荡）

## 2. DMIT 云主机环境搭建（首次）

### 2.1 安装系统依赖

```bash
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y \
    git python3 python3-pip python3-dev \
    gcc-arm-none-eabi libnewlib-arm-none-eabi \
    build-essential cmake pkg-config
```

### 2.2 安装 ArduPilot 编译环境

```bash
# 克隆代码（先拉到本地）
mkdir -p ~/workspace && cd ~/workspace

git clone https://github.com/codesoldier99/TG700.git TG700
cd TG700

# 切换到目标分支
git checkout claude/adapt-x8-coaxial-drone-BzNg0

# 初始化子模块（ArduPilot 依赖大量子模块，约 1-2 GB）
git submodule update --init --recursive

# 安装 ArduPilot 官方依赖脚本（自动处理 arm-gcc 版本等问题）
# 注意：此脚本会修改 ~/.profile，需要重新登录或 source
sudo Tools/environment_install/install-prereqs-ubuntu.sh -y

# 重新加载环境变量
. ~/.profile
```

### 2.3 验证编译环境

```bash
# 检查 ARM 编译器版本（应为 10.x 或更新）
arm-none-eabi-gcc --version

# 检查 Python 版本（应为 3.6+）
python3 --version

# 检查 waf 可用性
./waf --version
```

## 3. 编译固件

### 3.1 配置目标板

```bash
cd ~/workspace/TG700

# 配置 ZeroOne M9 目标板（仅首次或切换目标板时执行）
./waf configure --board ZeroOneM9
```

预期输出：
```
Setting top to: /home/user/workspace/TG700
Setting out to: /home/user/workspace/TG700/build
...
'configure' finished successfully
```

### 3.2 编译 ArduPlane

```bash
# -j$(nproc) 使用全部 CPU 核心加速编译
./waf plane -j$(nproc)
```

DMIT 云主机（4核）预计编译时间：**约 8-15 分钟**（首次全量）

增量编译（仅修改了部分文件）：**约 1-3 分钟**

### 3.3 输出文件

```
build/ZeroOneM9/bin/arduplane.apj   ← Mission Planner 烧写固件
build/ZeroOneM9/bin/arduplane.elf   ← GDB 调试用（可选）
```

## 5. 固件烧写

### 方法一：Mission Planner（推荐）

1. 将 `arduplane.apj` 从服务器下载到本地  
2. Mission Planner → 初始设置 → 安装固件  
3. 点击"自定义固件"→ 选择 `arduplane.apj`  
4. 等待烧写完成，飞控自动重启

### 方法二：MAVProxy（命令行）

```bash
# 通过串口或 USB 连接飞控后
mavproxy.py --master=/dev/ttyUSB0 --baud=115200
# 在 MAVProxy 命令行中：
wp load arduplane.apj
```

## 6. 参数加载

固件烧写后，通过 Mission Planner 加载参数文件：

```
CONFIG → Full Parameter Tree → Load from file
```

| 模式 | 参数文件 |
|---|---|
| 16电机 COAX16 | `docs/COAX16_flight.param` |
| 8电机 X8 | `docs/X8_flight.param` |

加载后：
1. 点击 **Write Params**
2. 断电重启飞控
3. 执行加速度计六面校准 + 水平校准
